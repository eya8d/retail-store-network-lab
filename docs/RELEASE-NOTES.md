# v1.0.0 — Retail Store Network Lab

My first single-store Packet Tracer lab, with separate networks for checkout, Office, Warehouse, servers, Guests and network management.

Included:
- Six VLANs with router-on-a-stick routing.
- DHCP and internal/external DNS/HTTP services.
- PAT for Office and Guests.
- Access rules for POS, Warehouse and Guests.
- Admin-only SSH access to store network devices.
- Sticky MAC port security, PortFast, BPDU Guard and unused-port shutdown.
- Topology, configuration notes and screenshots.

Open Retail-Store-Network.pkt in Cisco Packet Tracer. External web access is simulated inside the lab.

The configuration snapshots are from before the final cleanup; the build folder has cleaned rebuild configurations. I still need to record the exact Packet Tracer version and upload fresh final exports.
